موقع حرب أكتوبر - جاهز للنشر كموقع ثابت على Vercel

الملفات الأساسية:
- index.html
- style.css
- script.js

طريقة النشر:
1) فك ضغط الملف.
2) افتح Vercel وأنشئ مشروعًا جديدًا (Add New > Project).
3) ارفع مجلد vercel_october_site أو اربطه بمستودع Git يحتوي هذه الملفات في الجذر.
4) اختر Other كإطار عمل إن طُلب ذلك، واترك Build Command و Output Directory فارغين/افتراضيين لموقع HTML ثابت.
5) اضغط Deploy.
